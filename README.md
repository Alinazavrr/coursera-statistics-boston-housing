# Boston Housing statistics project

Executed course project for Statistics for Data Science with Python.

Open [the completed notebook](Boston-Housing-Alinazar-Zharkyn.ipynb) to view the code,
statistical results and six embedded plots. It covers data inspection, descriptive
statistics, Levene's test, a Welch t-test, one-way ANOVA, Pearson correlation and
simple linear regression.

The notebook loads the public [course dataset](https://cf-courses-data.s3.us.cloud-object-storage.appdomain.cloud/IBMDeveloperSkillsNetwork-ST0151EN-SkillsNetwork/labs/boston_housing.csv).
If a local copy of that CSV is present, it uses the local file instead. All outputs
are already included in the notebook.

The analysis defines its AGE groups explicitly and interprets associations without
claiming causal effects.
